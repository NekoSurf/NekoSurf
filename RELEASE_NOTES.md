## What's new

### 🚫 Thread filters
Hide threads you don't want to see by keyword or regex.
- Manage filters under **Settings → Threads → Hidden threads**
- Long-press any thread in a board to hide it by its title or comment
- "Add & add another" lets you enter several filters in a row
- Matching is case-insensitive and checks both the title and the comment

### 🏠 Home screen
- Slimmer greeting card at the top
- "Your feed" now lives in the Favorites section
- **Continue** cleans itself up: threads that were deleted disappear, and archived ones get an *Archived* badge
- Removed the "Recent boards" row

### 🖼️ Media viewer
- Removed the page dots on the right; the "3 of 12" counter in the top bar shows your position

## Fixes
- Fixed a crash on launch on iOS 17.0–17.5, and the minimum iOS version is now **17.0** (was 17.6)
- The filter input no longer autocorrects or swaps in smart quotes/dashes, which could break regex patterns
- Long-press filters now match text literally, even when titles contain characters like `|`, `?` or `()`
- Fixed AltStore download links for recent versions

Thanks to @CannibalToast for the thread filters and the iOS 17 fix!
