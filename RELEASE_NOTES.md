## ⚠️ Android: please reinstall once

Android builds are now signed with a permanent release key. Until now, every release was signed with a different temporary key, which is why updating through Obtainium (or installing over an older version) failed with **"Signing certificate mismatch"** / **failureConflict**.

**To switch to the new builds, uninstall NekoSurf once and install this version.** Uninstalling removes the app's data on your device (bookmarks, history and saved attachments), so save anything you want to keep to your gallery first.

From this release on, updates install normally, no reinstall needed.

iOS is not affected.
